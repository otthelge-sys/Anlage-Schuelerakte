# Schülerakte anlegen

Formularseite der Klinikschule Dothanschule zum Anlegen einer Schülerakte für GoodNotes.

Die Seite enthält nur das leere Formular und die Programmlogik. Alle Eingaben und ausgewählten Dateien werden ausschließlich lokal im Browser verarbeitet und nicht übertragen.

Bitte niemals ausgefüllte Akten, Datendateien oder Schülerlisten in dieses Repository hochladen.
